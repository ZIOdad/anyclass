# 접수 직후 다시 제출해 검증에 실패하면 이전 건의 접수 완료 배너가 오류와 함께 보인다

**Symptom**: 정상 접수 뒤 `/report?submitted=<id>` 상태에서 "아"처럼 너무 짧은 내용을 제출하면 "이렇게 접수되었습니다"(이전 건)와 "한 줄만 더 자세히 적어 주세요" 오류가 한 화면에 같이 보인다.

**Observed evidence**: 로컬 개발 서버(`bun run dev`)에서 임차인 계정으로 접수 후 `#body`에 "아"를 제출했을 때 확인. 입력 유지와 접수 건수 유지는 정상이다.

**Suspected cause**: 배너가 서버 컴포넌트에서 URL의 `submitted` 파라미터로만 결정되고, 폼의 오류 상태(클라이언트 `useActionState`)를 알지 못한다.

**What was tried**: 없음. 접수와 검증 동작 자체는 spec의 수용 기준을 만족해 고치지 않고 남겼다.

**Proposed next step**: 오류가 있을 때 배너를 숨기거나, 접수 결과 표시를 폼과 같은 클라이언트 상태로 옮긴다.
